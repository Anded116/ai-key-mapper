# ai-key-mapper

Наследник JoyShockMapper: раскладку геймпада под каждую игру настраивает ИИ-агент. Устройство и этапы — в [docs/architecture.md](docs/architecture.md).

## Запуск

| Файл | Что делает |
|---|---|
| `TestRange.cmd` | Собирает (если есть Rust) и запускает тестовый шутер [TestRange](demo/README.md). |
| `TestRange + JSM.cmd` | То же, плюс поднимает JoyShockMapper v3.6.1 с пресетом из `jsm/`. Если JSM нет, скачивает его в `tools/`. |
| `TestRange + aikm.cmd` | То же, но вместо JSM работает наш движок `aikm` с профилем `profiles/testrange.toml`: геймпад скрыт от игры через HidHide (подсказки не мигают), левый стик — WASD с шагом при неполном отклонении. Гибрид со стиком в игре — `profiles/testrange-hybrid.toml`. Профиль перечитывается при сохранении, PS + Create — пауза, Ctrl+C в окне aikm — выход с отпусканием всех клавиш. |
| `aikm.cmd` | Только движок с автозагрузкой профилей (без TestRange). Проверка переключения: запусти `aikm.cmd`, потом `TestRange.cmd`; в окне TestRange профиль подхватится, на рабочем столе движок замолчит. |
| `App.cmd` | Окно ai-key-mapper: живая схема DualSense, статус движка, пауза и калибровка, миничат агента. Окно само работает маппером, как `aikm.cmd`: профиль выбирается по игре в фокусе. Поэтому вместе с ним запускай просто `TestRange.cmd`, а `aikm` и JSM держи закрытыми. |
| `Probe.cmd` | Живое состояние геймпада: стики, кнопки, курки, гироскоп, тачпад. `Probe.cmd --still 3` — замер смещения и шума гироскопа в покое. |

Перед `TestRange + JSM.cmd` закрой свой JoyShockMapper и положи геймпад на стол: первые 3 секунды идёт калибровка гироскопа. Пресет загружается сам, когда в фокусе окно TestRange (AutoLoad JSM). Пока JSM запущен, гироскоп двигает мышь и в других окнах, поэтому после теста закрой консоль JSM.

Без JSM демка с геймпада читает только левый стик: гироскоп, flick stick и остальные кнопки приходят от JSM как клавиатура и мышь.

## Раскладка TestRange (DualSense)

Общий стандарт, из которого собрана эта раскладка, и приёмы JSM для других игр описаны в [docs/layout-standard.md](docs/layout-standard.md).

| Кнопка | Действие |
|---|---|
| L1 | прыжок |
| R1 | огонь |
| L2 | прицел |
| R2 + □ / ✕ / ○ / △ | оружие 1/2, 3/4, 5/6, 7/8: первое нажатие — нечётный слот, повторное — чётный |
| Правый стик | flick stick; гироскоп — мышь |
| Касание тачпада | гироскоп выключен, пока палец на тачпаде |
| Клик тачпада: левая / правая половина | справка / отладочный HUD |
| Левый стик | движение: игра читает стик сама (гибрид) |
| R2 + L3 | переключить левый стик: гибрид ↔ WASD с шагом при неполном отклонении (в JSM и в aikm) |
| L3 | спринт |
| R3 | удар ножом |
| ✕ □ △ ○ | использовать, перезарядка, граната, присед |
| Крестовина ↑ ↓ ← → | фонарик, метка, инвентарь, карта |
| Options | пауза |
| Create | статистика, пока держишь |
| R2 + Create / Options | быстрое сохранение / загрузка |
| Mic | сброс счётчиков |
| PS: тап / удержание | переключить калибровку / калибровать, пока держишь |

Выбор оружия устроен как в старых пресетах: каждое нажатие подгружает файл состояния из `jsm/Presets/TestRange/`. Световая полоса показывает состояние: серая — все кнопки дадут первое оружие; розовая, синяя, красная или зелёная — следующее нажатие □, ✕, ○ или △ даст второе оружие этой кнопки.

В JSM это держится на файлах состояния: строку `ZR,N,N` (аккорд плюс двойное нажатие) его парсер не принимает. Движок `aikm` повторяет то же поведение без файлов, полем `next` в профиле: повторное нажатие той же кнопки даёт второе оружие пары в любой момент, другая кнопка начинает свою пару заново. Состояние по-прежнему может разойтись с игрой, если оружие сменили иначе (клавишей, подбором).

Чтобы проверить режим WASD, переключи стик через R2 + L3 и выключи в меню демки (Esc) пункт «Движение стиком геймпада»: иначе демка продолжит читать аналоговый стик напрямую.

## Движок aikm

- `aikm run profiles	estrange.toml` — один профиль; `aikm run profiles` (или `aikm.cmd`) — автозагрузка, как AutoLoad в JSM: профиль выбирается по `exe` окна в фокусе. Профиль действует, только пока его игра в фокусе: на рабочем столе и в других окнах движок молчит, гироскоп мышь не двигает.
- Подсказка пары подсветкой у тачпада выключена; включается в профиле: `[lightbar] enabled = true`.
- PS: тап включает калибровку гироскопа, второй тап завершает; удержание калибрует, пока держишь. Толчки от нажатия и отпускания отбрасываются, результат пишется в окне aikm.
- Адаптивные триггеры выключаются при подключении геймпада.
- `[controller] hide = true` в профиле прячет геймпад от игр через HidHide, пока работает aikm и стик в режиме WASD. В режиме стика (R2 + L3) геймпад снова виден игре. Игру с таким профилем запускай после aikm: уже открытая игра продолжает видеть геймпад.
