# ai-key-mapper

Наследник JoyShockMapper: раскладку геймпада под каждую игру настраивает ИИ-агент. Пока в репозитории есть тестовая игра и пресет JSM для неё.

## Запуск

| Файл | Что делает |
|---|---|
| `TestRange.cmd` | Собирает (если есть Rust) и запускает тестовый шутер [TestRange](demo/README.md). |
| `TestRange + JSM.cmd` | То же, плюс поднимает JoyShockMapper v3.6.1 с пресетом из `jsm/`. Если JSM нет, скачивает его в `tools/`. |

Перед `TestRange + JSM.cmd` закрой свой JoyShockMapper и положи геймпад на стол: первые 3 секунды идёт калибровка гироскопа. Пресет загружается сам, когда в фокусе окно TestRange (AutoLoad JSM). Пока JSM запущен, гироскоп двигает мышь и в других окнах, поэтому после теста закрой консоль JSM.

Без JSM демка с геймпада читает только левый стик: гироскоп, flick stick и остальные кнопки приходят от JSM как клавиатура и мышь.

## Раскладка TestRange (DualSense)

| Кнопка | Действие |
|---|---|
| L1 | прыжок |
| R1 | огонь |
| L2 | прицел |
| R2 + □ / ✕ / ○ / △ | оружие 1/2, 3/4, 5/6, 7/8: первое нажатие — нечётный слот, повторное — чётный |
| Правый стик | flick stick; гироскоп — мышь |
| Касание тачпада | гироскоп выключен, пока палец на тачпаде |
| Клик тачпада: левая / правая половина | метка / справка |
| Левый стик, L3 | WASD, бег |
| ✕ □ △ ○ | использовать, перезарядка, прошлое оружие, присед |
| R3 | удар |
| Крестовина ↑ ↓ ← → | граната, фонарик, пред. / след. оружие |
| Options: тап / удержание | пауза / карта |
| Create: тап / удержание | инвентарь / статистика |
| R2 + Create / Options | быстрое сохранение / загрузка |
| Mic | сброс счётчиков |
| PS: тап / удержание | переключить калибровку / калибровать, пока держишь |

Выбор оружия устроен как в старых пресетах: каждое нажатие подгружает файл состояния из `jsm/Presets/TestRange/`. Нативно JSM так не умеет: строку `ZR,N,N` (аккорд плюс двойное нажатие) его парсер не принимает, он допускает только один оператор `ZR,N`. Поэтому состояние может разойтись с игрой. Например, после `R2+□` (слот 1) смена оружия колесом не сбрасывает состояние, и следующее `R2+□` даст слот 2. В нашем приложении это нужно сделать нативно, с окном двойного нажатия.
