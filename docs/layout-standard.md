# Стандарт раскладки DualSense для шутеров

Основа для всех игровых профилей: этот файл читает агент, когда собирает пресет под новую игру. Ядро одинаково везде, поэтому мышечная память переносится между играми. Под конкретную игру меняются только переменные из раздела 3.

## 1. Ядро — одинаково во всех играх

| Кнопка | Действие |
|---|---|
| L1 | прыжок |
| R1 | огонь |
| L2 | прицел |
| R2 | слой: сам ничего не делает, переключает лицевые кнопки на оружие (раздел 2) |
| Правый стик | flick stick; гироскоп — мышь |
| Касание тачпада | гироскоп выключен, пока палец на тачпаде (перехват, как поднять мышь) |
| PS | калибровка гироскопа: тап — вкл/выкл, удержание — пока держишь |
| L3 | спринт |
| R3 | удар (ближний бой) |
| ○ | присед |
| ✕ | использовать / взаимодействие |
| □ | перезарядка |
| △ | граната / способность (второе боевое действие игры) |
| Options: тап / удержание | пауза / карта |
| Create: тап / удержание | инвентарь / журнал (статистика) |
| Mic | редкая функция игры (фото-режим, чат, бинокль) |
| Клик тачпада, левая / правая половина | две редкие функции |
| Крестовина | предметы (аптечка, фонарик, метка); диагонали — ещё четыре предмета |

Не используем: «пред./след. оружие» и перелистывание стрелками. Выбор оружия — только через слой R2.

## 2. Слой R2

| Комбинация | Действие |
|---|---|
| R2 + □ ✕ ○ △ | оружие: 4 слота (по одному на кнопку) или 8 (первое нажатие — нечётный, повторное — чётный) |
| R2 + Create / Options | быстрое сохранение / загрузка |
| R2 + L3 | переключить движение: гибрид ↔ WASD |
| R2 + R1 | альтернативный огонь (если есть) |
| R2 + L1 | способность / рывок (если есть) |
| R2 + крестовина | предметы 9–12, если обычных не хватает |

Раскладка оружия по кнопкам: □ 1/2, ✕ 3/4, ○ 5/6, △ 7/8. Когда в игре только 4 оружия, это □ 1, ✕ 2, ○ 3, △ 4. Так обычно бывает в консольных портах, где оружие на крестовине.

## 3. Переменные профиля под игру

| Переменная | Варианты | Как выбрать |
|---|---|---|
| Оружие | 4 / 8 слотов | сколько цифр выбора оружия в игре |
| Движение | гибрид / WASD | гибрид, если игра читает геймпад одновременно с мышью без мигания подсказок; иначе WASD |
| Шаг в WASD | внутреннее кольцо → клавиша шага | только если в игре есть клавиша шага |
| Спринт | L3 / полное отклонение стика | полное отклонение (`LEFT_RING_MODE = OUTER`, `LRING = LSHIFT`) — если в игре спринт удержанием |
| Присед | удержание / переключение | если в игре присед только переключением, конвертировать в удержание (раздел 4) |
| Калибровка | `REAL_WORLD_CALIBRATION`, `IN_GAME_SENS` | из GyroWiki или по замеру поворота на 360° |
| Режим техники | загрузка отдельного файла | для полёта и вождения: виртуальный Xbox-геймпад, как в Starfield |

## 4. Приёмы JSM, которые стоит держать под рукой

Синтаксис проверен по README JoyShockMapper 3.6.1.

**Тап / удержание** — удваивает кнопку: первая клавиша на тап, вторая на удержание (`HOLD_PRESS_TIME`, по умолчанию 150 мс).
```
+ = ESC M
```

**Шаг при неполном отклонении** — главное лекарство от «стик как WASD» в играх без поддержки геймпада.
```
LEFT_RING_MODE = INNER
LRING = LALT
```

**Автоспринт при полном отклонении** — вместо L3, если спринт в игре удержанием.
```
LEFT_RING_MODE = OUTER
LRING = LSHIFT
```

**Полное нажатие L2** — второе действие на тот же курок: прицел на мягком нажатии, задержка дыхания или кратность прицела на полном. С адаптивными триггерами DualSense порог ощущается пальцем.
```
ZL_MODE = NO_SKIP
ZL = RMOUSE
ZLF = LSHIFT
```

**Чувствительность гироскопа в прицеле** — только если игра сама не снижает чувствительность при прицеливании, иначе эффект удвоится.
```
ZL,MIN_GYRO_SENS = 1.2
ZL,MAX_GYRO_SENS = 1.8
```

**Переключение в удержание** — когда игра делает присед или прицел переключателем, а хочется держать.
```
E = !LCONTROL\ !LCONTROL/
```

**Турбо для QTE** — удержание шлёт клавишу пачкой.
```
MIC,S = SPACE+
```

**Диагонали крестовины** — ещё четыре кнопки без новых комбинаций.
```
UP*RIGHT = 5
RIGHT*DOWN = 6
DOWN*LEFT = 7
LEFT*UP = 8
```

**Одновременное нажатие L3 + R3** — «ультимейт» или особый режим (так в Dying Light: The Beast).
```
L3+R3 = Z
```

**Свайпы по тачпаду** — четыре направления на каждой половине.
```
TOUCH_STICK_RADIUS = 800
T1,TLEFT = 1
T1,TUP = 2
```

**Наклон геймпада** — для тактических шутеров с выглядыванием из-за угла.
```
LEAN_LEFT = Q
LEAN_RIGHT = E
LEAN_THRESHOLD = 15
```

**Световая полоса как индикатор состояния** — любой файл режима ставит свой цвет. В TestRange так подсвечивается, какая кнопка следующим нажатием даст второе оружие.
```
LIGHT_BAR = xFF3CA0
```

**Режимы как отдельные файлы** — пешком / техника / меню, переключение кнопкой.
```
+ = "Presets/Game/vehicle.txt"\
```

Настройки flick stick, которые стоит пробовать, если стик ощущается не так:
- `FLICK_DEADZONE_ANGLE = 10…15` — толчок стика почти вперёд не даёт флика, а сразу переходит в поворот;
- `FLICK_TIME` (0,1 с) — скорость самого флика;
- `FLICK_TIME_EXPONENT = 1` — короткие флики быстрее длинных;
- `STICK_DEADZONE_OUTER` — с какого отклонения начинается флик;
- `GYRO_SPACE = PLAYER_TURN` — гироскоп учитывает наклон геймпада, поворот естественнее, когда геймпад держат не горизонтально.

## 5. Чего JSM не умеет — это делает наше приложение

- **R2 + двойное нажатие без файлов состояния.** Парсер JSM принимает только один оператор (`ZR,N`), строку `ZR,N,N` он не разберёт. Сейчас выбор оружия 1–8 держится на файлах состояния и расходится с игрой, если оружие сменили иначе. Нужно нативно: окно двойного нажатия внутри слоя.
- **Показать состояние на экране**, а не только световой полосой.
- **Определить режим движения сам**: запустить игру, проверить, мигают ли подсказки при смешанном вводе, и выбрать гибрид или WASD.
- **Скрывать геймпад от игры** без ручной возни с HidHide — см. [hid-hiding.md](hid-hiding.md).
- **Калибровать `REAL_WORLD_CALIBRATION` замером**, а не подбором.
